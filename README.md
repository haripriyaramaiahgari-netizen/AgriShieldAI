# 🌾 AgriShieldAI

> **AI-Powered Pest Outbreak Prediction & Early Warning Network**

AgriShieldAI is a web-based application designed to assist farmers by providing early pest outbreak predictions based on the selected crop and location. The system also displays weather information, AI confidence level, pest risk, and crop protection recommendations to support timely decision-making.

---

## 📖 Project Overview

Pest attacks are one of the major reasons for crop loss in agriculture. Delayed detection often results in reduced crop yield and financial loss for farmers.

AgriShieldAI provides a simple interface where users can:

- Upload a crop image
- Select the crop type
- Enter the farming location
- Receive an AI-based pest prediction
- View weather information
- Get recommended pest control measures
- Download the prediction report

The project demonstrates how Artificial Intelligence concepts can be integrated into agriculture to support smarter farming practices.
